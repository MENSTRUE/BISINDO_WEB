# BISINDO Web

Web-based BISINDO recognition project.

## Planned architecture

- Frontend: React + Vite
- Backend: FastAPI + WebSocket
- Vision: OpenCV + MediaPipe
- Inference: PyTorch TorchScript
- Models:
  - v1: word recognition
  - v2: alphabet recognition
